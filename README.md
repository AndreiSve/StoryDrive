# StoryDrive

Генератор рекламных сторис 1080×1920 из XML-фида MaxPoster. У каждого пользователя свой аккаунт, сессия и сохранённая ссылка на фид.

## Что входит

- вертикальный редактор сторис и экспорт PNG;
- оформление в зелёном и красном цвете;
- цена, «1 владелец» и «Зелёная Автотека»;
- регистрация, вход и защищённые cookie-сессии;
- PostgreSQL для пользователей и сохранённых фидов;
- проверка формата XML, ограничение 20 МБ и отмена через 2 минуты;
- Dockerfile для Timeweb Cloud App Platform.

## Локальный запуск

Нужен Docker Desktop.

```bash
docker compose up --build
```

Откройте `http://localhost:8080`. При первом запуске таблицы PostgreSQL создаются автоматически.

## Развёртывание на Timeweb Cloud

Подробная пошаговая инструкция находится в [DEPLOY-TIMEWEB.md](DEPLOY-TIMEWEB.md).

Минимально приложению нужны переменные:

```env
NODE_ENV=production
PORT=8080
DATABASE_URL=postgresql://USER:PASSWORD@HOST:PORT/DATABASE
DATABASE_SSL=require
```

Если приложение и PostgreSQL соединены приватной сетью без TLS, задайте `DATABASE_SSL=disable`. Для строгой проверки TLS-сертификата передайте сертификат в Base64 через `DATABASE_CA_BASE64`.

## Безопасность

- пароль хэшируется PBKDF2-SHA-256 с индивидуальной солью и 210 000 итераций;
- сервер хранит только SHA-256 хэш токена сессии;
- в production cookie имеет `HttpOnly`, `Secure`, `SameSite=Lax`;
- прокси принимает только HTTPS-адреса `maxposter.ru`;
- загрузка фида ограничена 20 МБ и 2 минутами;
- тариф и статус аккаунта уже заложены в схему БД для будущей монетизации.

Каталог `cloudflare/` оставлен локально как архив предыдущей реализации и не входит в репозиторий или Docker-образ.
